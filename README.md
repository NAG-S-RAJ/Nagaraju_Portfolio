# Nagaraju S M Portfolio

Static portfolio for an embedded software engineer, built with HTML, CSS, and a small amount of vanilla JavaScript.

## Structure

- `index.html` is the portfolio entry point.
- `styles/portfolio.css` contains layout and responsive styles.
- `scripts/portfolio.js` updates the reading progress and active section in the navigation.
- `assets/images/` contains the portrait and favicon.
- `assets/documents/` contains the downloadable resume.

Open `index.html` in a browser to view the portfolio.
